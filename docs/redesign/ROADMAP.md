## Phase 4 — Migration tooling + dual-backend transition + per-page provider snapshot

> **PRECEDES** Phase 5 (embedding default-flip). The Phase 4 → Phase 5 ordering
> is non-negotiable. Reversing it silently breaks every existing v0.6.0 KB.

**Objective:** ship migration tooling, dual-backend read-fallback, and per-page
`(embedding_provider, embed_base_url)` snapshots BEFORE the embedding default
flip.

### Files to read

- `src/agent_knowledgebase/database.py`
- `src/agent_knowledgebase/services/embeddings.py` (existing `create_embedder_for_model`)
- Phase 2 backend interfaces

### Files to touch

- `src/agent_knowledgebase/services/migration.py` (NEW — `export_to_markdown`, `import_from_markdown`, `export_chromadb_dump`, `import_chromadb_dump`)
- `src/agent_knowledgebase/server.py` — add `kb_migrate(kb_id, target_backend)` MCP tool (additive — probe-4-safe, NOT in the 25 frozen list)
- `src/agent_knowledgebase/database.py` — schema migration: `ALTER TABLE pages ADD COLUMN embedding_provider TEXT; ALTER TABLE pages ADD COLUMN embed_base_url TEXT;`
- `src/agent_knowledgebase/services/embeddings.py` — change `create_embedder_for_model` signature to accept `(model_name, provider, base_url)` tuple read from per-page snapshot
- `docs/migration_guide.md` (NEW)

### Read-fallback semantics

If `Settings.kb_backend='markdown'` but `<kb-name>/wiki/` does not exist while
`<kb-name>/vector_store/` does, `ChromadbBackend` serves the query. Silent
fallback emits a `phase='read_fallback'` line via `knowledgebase_stderr_log`.

### `migration_complete` sentinel

Written to `<saves_dir>/<kb-name>/.migrated_to=<backend>` when `kb_migrate`
succeeds. Cutover criterion.

### `AGENT_KB_BACKEND_PER_KB`

Comma-separated `kb_id=backend` pairs override global `Settings.kb_backend`
per KB.

### Tests to add

- `tests/test_migration_chromadb_to_markdown.py` — ingest under chromadb, run migrate, assert `wiki/` created, assert `kb_query` routes to markdown, assert old chromadb collection still readable until cutover sentinel written
- `tests/test_per_page_provider_snapshot.py` — ingest under `provider=ollama`, flip global default to `provider=remote`, assert query still uses Ollama embedder for the original page (read-fallback uses snapshot)

### Backfill script

Existing pages get `embedding_provider` and `embed_base_url` populated from
each KB's `config.json` before Phase 5 may merge.
